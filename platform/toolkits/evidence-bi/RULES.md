# Reporting rules

- **Metric-first.** Every number on a page traces to a metric in
  `queries/metrics/`. A figure with no metric is a metric PR, not page SQL.
- **Generated files are not editable.** `queries/metrics/**`, `pages/index.md`
  and `pages/metrics/**` are regenerated by `pf report build`. The gate denies
  writes to compiled queries; editing one makes a page silently disagree with its
  own metric definition.
- **Never `avg(ratio)`.** Ratio queries carry numerator and denominator so pages
  re-divide at their grain: `sum(num)/sum(den)`.
- **Palette comes from `evidence.config.yaml` only.** It is validated for
  colour-vision deficiency and contrast in both themes. A hex value typed into a
  page is unvalidated by definition.
- **Page anatomy, in order:** title + one context sentence → one filter row →
  KPI row → primary trend → breakdowns → detail table. Never a wall of charts.
- Run `pf report audit <group> <project>` before calling a page done.

## Toolchain

Evidence 40 builds on **Node 20** (`.nvmrc` in `reporting/`). On Node 24 / npm 11
`npm run build` fails inside Vite/Rollup — a pristine `evidence-dev/template`
fails identically, so it is Evidence's runtime boundary, not this project. Do not
re-diagnose it: `nvm use 20`. `npm run sources` and `npm run dev` are unaffected.
