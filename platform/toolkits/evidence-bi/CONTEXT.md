# evidence-bi

BI as code, compiled from the semantic layer. A figure a page needs but no metric
provides is a missing definition, not a reason to write SQL into the page — two
pages filtering differently is how one company ends up with two revenues.

`avg(ratio)` is the most common BI bug there is: it is wrong at every grain
except the one it was computed at, and it looks right in every spot check.
