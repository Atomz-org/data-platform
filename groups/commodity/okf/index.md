# commodity ontology

Generated by `pf tool okf build --group commodity` from `groups/commodity/ontology/`. What
this family declared on top of the platform vocabulary — the terms a steward approved,
or that were written by hand when no platform class described the business. Every
sister in `commodity` shares exactly this; another family never inherits a word of it.

Everything else this family uses is the platform's: [Platform ontology](../../../platform/okf/index.md).

# Concepts

* [Commodity](/concepts/Commodity.md) - A traded raw material with an international benchmark, quoted per a physical unit.
* [FxRate](/concepts/FxRate.md) - A daily exchange-rate fix — units of quote currency per one unit of base currency.
* [ImportTariff](/concepts/ImportTariff.md) - Customs duty a jurisdiction levies on importing a commodity, valid over an interval.
* [Market](/concepts/Market.md) - A jurisdiction commodities are landed in — one sister project, one currency, one customs regime. The tenant of this family.
* [PriceObservation](/concepts/PriceObservation.md) - One benchmark price for one commodity at one point in time. Never summed.

# Roles

* [exchange_rate](/roles/exchange_rate.md) - Units of quote currency per one unit of base currency.
* [flag](/roles/flag.md) - A true/false state of the row (prohibited, confirmed). Passes through staging; never aggregated.
* [rate_fraction](/roles/rate_fraction.md) - A proportion stored as a fraction — 0.15 means 15%.
* [reference_date](/roles/reference_date.md) - A date the row refers to that is not its own event time — the FX fix a price used, the day a duty was confirmed. No freshness monitor.
* [unit_of_measure](/roles/unit_of_measure.md) - Physical unit a quantity or price is expressed per (troy_oz, lb, metric_ton, ...). Codes are the group units_of_measure seed.
* [unit_price](/roles/unit_price.md) - Price of one unit of measure. Non-additive — never summed across rows. Qualified by a sibling currency_code and a unit_of_measure.
